# 一人暮らし ヒアリングシート

大学進学にあわせて一人暮らしをしたい高校生が、**親に見せる資料を「シラバス」の形で作る**ためのヒアリングシートです。

答えていくと、次の3つが出てきます。

1. **シラバスの下書き**（概要／目的／到達目標／授業計画／費用／成績評価／履修上の注意／スケジュール）
2. **費用の検算** — 月に増える額、4年間の差額、自分で出せる額、足りない額
3. **次にやること** — どこで何を調べるかまで書いた、優先順位つきのリスト

## 考え方

- 前半は**気持ち**の章。調べても出てこない、本人にしか書けないところ
- 後半は**数字**の章。各設問に「取る数字／どこで／目安・検算／よくある間違い」を付けてある
- 金額には**出典と確認日**を記録する欄がある。出典のない数字が1つあると、資料全体が疑われるため

## 使い方

ブラウザで開くだけです。ビルドもサーバーも要りません。

回答は**その端末の localStorage にのみ保存**され、どこにも送信されません。
最後に「コピー」または「ファイルで保存」で Markdown として書き出せます。

## 中の数字について

学費は立命館大学の公式ページ（2027年度入学者）で2026年10月27日に確認した額を入れてあります。
家賃相場や生活費は目安であり、**必ず自分で調べ直す**前提で「調べ方」を書いています。

## プレゼン

ヒアリングの回答から作った、親に向けた説明用スライドです。

- ソース：`presentation.qmd`（Quarto / revealjs）
- 公開：<https://shota-kawakami.github.io/hitorigurashi-syllabus/presentation.html>
- 再レンダリング：`quarto render presentation.qmd`

金額のうち、出典が確認できているのは学費だけです。家賃・初期費用・生活費は目安を仮置きしてあり、
スライド内でも「まだ決まっていないこと」として明示しています。差し替えてから親に見せる前提です。
